# Semana 1b - Manejo de Strings
## ================= ENUNCIADO =================
La entrada de nuestro programa son varias líneas de texto compuestas de letras y números. En cada línea debemos combinar el primer  y el último dígito (en este orden) para formar un número de dos dígitos.

Escribe el código en Python que calcule la suma de todos los números de dos dígitos asociados a todas las líneas de texto
de la entrada.

Por ejemplo, suponiendo esta entrada:

1abc2
pqr3stu8vwx
a1b2c3d4e5f
treb7uchet

... los números de dos dígitos de estas 4 líneas son: 12, 38, 15, 77 y el resultado que debe generar el programa es la suma de estos 4 
números: 12 + 38 + 15 + 77 = 142
