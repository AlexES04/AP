## ================= NOTAS =================
En la solución de este ejercicio, se destaca el uso de un _set_ para llevar la cuenta de los nodos visitados (_visited_). En un algoritmo BFS, hace falta buscar elementos en una lista, conjunto, array... En una lista, el tiempo que toma es lineal viniendo representado por `O(V)`, mientras que en un _set_ el tiempo que toma es constante, `0(1)`.
