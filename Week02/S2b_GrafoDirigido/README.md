# Semana 2b - Grafo Dirigido
## ================= ENUNCIADO =================
Dado una lista de vértices, el número de nodos y el número de vértices, se debe desarrollar una función que permita crear un grafo dirigido con la biblioteca _minigraph_. 

## ================= NOTAS ================
En la solución de este ejercicio, se destaca el uso de funciones de _minigraph_ para añadir nodos (`add_node(u)`) y para añadir vértices (`add_edge(u, v)`).
