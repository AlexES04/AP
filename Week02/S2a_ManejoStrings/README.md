# Semana 2a - Manejo de Strings
## ================= ENUNCIADO =================
La entrada de nuestro programa son varias líneas de texto con letras y números, pero los números pueden estar como dígitos (1,2,3,4,5,6,7,8,9) o como texto (one, two, three, four, five, six, seven, eight, nine). En cada línea debemos combinar el primer y el último dígito (en este orden) para formar un número de dos dígitos.

Escribe el código en Python que calcule la suma de todos los números de dos dígitos asociados a todas las líneas de texto de la entrada.

### Ejemplo
#### Entrada
two1nine

abcone2cdthreexyz

xtwone3fo

treb7uchzoneet

#### Salida
Los números de dos dígitos de estas 4 líneas son: 29, 13, 23, 71. Por tanto, el resultado que debe generar el programa es la suma de estos 4 números: 19 + 13 + 23 + 71 = 136
