# Semana 3a - Distancia de _Manhattan_
## ================= ENUNCIADO =================
Estamos situados sobre un tablero de tamaño infinito.
Comenzamos situados en una intersección cualquiera del tablero
orientados hacia el Norte, y nos movemos siguiendo una
secuencia de intrucciones que recibimos como entrada
de nuestro programa.

Cada instrucción nos dice si debemos girar hacia la izquierda
90 grados (L) o girar hacia la derecha 90 grados (R), y a
continuación el número de cuadrículas que debemos avanzar.

Escribe un programa en Python que, tras ejecutar las instrucciones,
calcule la distancia de Manhattan desde nuestra posición inicial
hasta las posición final de nuestro recorrido.

### Ejemplo
#### Entrada
```
4   # Nº instrucciones
R5
L5
R5
R3
```
#### Salida
```
12
```
